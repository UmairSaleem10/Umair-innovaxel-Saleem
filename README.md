# URL Shortener - MERN Stack Application

A complete URL shortening service built with the MongoDB, Express.js, Node.js that allows users to create, manage, and track short URLs.

## Features

- Create short URLs from long URLs
- Redirect to original URLs
- Update existing short URLs
- Delete short URLs
- View access statistics 

## Technologies Used

**Backend:**
- Node.js
- Express.js
- MongoDB (database)
- ShortID (for generating unique codes)

## Prerequisites

- Node.js (v14+)
- npm 
- MongoDB (local or Atlas URI)
